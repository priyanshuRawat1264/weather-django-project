Weather Application (Django)

A feature-complete weather forecasting application built with Django and integrated with the OpenWeatherMap API. This application allows users to search for cities worldwide and view current weather metrics, forecasts, and relevant weather data in a clean, user-friendly interface.

Features

Live Weather Updates: Real-time temperature, humidity, wind speed, and general weather conditions.

Search Functionality: Instant weather lookup for cities globally.

Clean UI: Responsive and modern template design.

Environment Configuration: Secure handling of API keys and configuration using standard .env patterns.
